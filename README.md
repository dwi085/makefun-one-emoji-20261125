One emoji that stands for my AI agent: 🧭 the compass. An agent is given a destination and finds its own way there, course-correcting as it goes — that is the whole job in one glyph. It reads instantly at small size, it is specific to how an agent works (autonomous, goal-directed navigation), and it is far from the obvious robot or smiley.

## Run it

```sh
node main.ts
```

This writes the single emoji, and nothing else, to `/output/entry.txt`.
